# dc-modlist

这个专案用于记录，我以优化为目的，对[亡者世界](https://www.curseforge.com/minecraft/modpacks/deceasedcraft)最新公测版的改动。

## 免责声明

我不保证这些优化有多少效果。因为游戏中有各种各样不同的场景，每个人的电脑配置也各不相同，我也不是什么专业的技术人员。所以请新建一个实例用于测试，以防影响到你的存档。

## 简介

文章内容包括原版整合包中所有模组的功能列表，以及我删除了哪些模组和添加了哪些模组。

> [!WARNING]
> 这个专案进行的改动较为激进，请针对自身的情况进行相应调整。

如果你有更好的方案或建议，可以创建议题或拉取请求。

## 议题

如果**明确**遇到删除或添加某个模组导致的游戏崩溃，请在议题中附上**完整**的错误日志

如果是**明确**遇到删除或添加某个模组导致的性能下降，请在议题中**至少**附上文字描述的测试记录。示例：

> 我用Entity Culling在某场景下帧数为160帧。而liubai在相同场景下，帧数为80帧，且肉眼明显感觉到卡顿。

如果嫌麻烦可以自己解决。搞这么麻烦是为了我能更好的解决问题。感谢每位愿意辛苦测试的同志！
